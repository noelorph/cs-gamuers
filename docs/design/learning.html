Making decisions with conditions

A program can choose what to do next by checking a condition. The condition evaluates to true or false.

Start with a familiar decision

Imagine a library kiosk checking whether a book is available. If it is, the kiosk offers a borrowing option. Otherwise, it explains that the book is on loan.

Think through each outcome

  1. Identify the condition: is the book available?
  2. Describe the action when it is true.
  3. Describe the action when it is false.

Clear conditions make the program easier to follow. Try describing both outcomes before writing the code.
